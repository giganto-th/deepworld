# DeepWorld

ลูกโลก 3 มิติที่แสดงความสูงของเปลือกโลก ทั้งบนบกและใต้มหาสมุทร เขียนด้วย Three.js และ custom shader

- ปรับการขยายความสูงได้ 1–100×, ปรับความเข้มของเงา, จำลองระดับน้ำทะเล (−6,000 ถึง +3,000 ม.)
- แสดงรอยต่อแผ่นเปลือกโลก (PB2002), ชี้เมาส์เพื่อดูพิกัดและความสูง, ปุ่มบินไปยังจุดสำคัญ
- ข้อมูลความสูง: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles) (Terrarium) โหลดตรงจากเบราว์เซอร์ ไม่ต้องใช้ API key

## รัน

```bash
python3 -m http.server 8173
```

แล้วเปิด http://localhost:8173
